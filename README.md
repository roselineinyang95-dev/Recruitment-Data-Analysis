# Recruitment-Data-Analysis
This project analyzes recruitment data from a consulting firm to identify trends in candidate sourcing, selection, and job placement.
Objectives
Analyze candidate flow from application to placement
Identify drop-off points in the recruitment processs
Evaluate effectiveness of sourcing channels
Provide data-driven recommendations to improve hiring success.
Data Description
Candidates Data(Applications Received)
Subscribers Data(Candidates in the job pool)
Compliance (Candidates successfully placed in jobs)
